# Quibbles Homepage Clone

A front-end clone of the [Quibbles](https://quibblesapp.com/) homepage — Nigeria's leading community platform.

Built as a team project by **Confidence** & **Abiodun**.

---

## 🚀 Features

- Responsive 3-column layout (Desktop + Mobile friendly)
- Clean Navbar with search
- Interactive Left Sidebar with Communities
- Realistic Main Feed with multiple post cards
- Right Sidebar (Trending + Rewards Hub)
- Hover effects and smooth transitions
- Pure HTML, CSS (Tailwind) & Vanilla JavaScript

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Font Awesome Icons
- Vanilla JavaScript
